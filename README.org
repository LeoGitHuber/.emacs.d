* Emacs Configuration
This is a fine-tuned Emacs configuration. It's fast enough to boot up and powerful enough to work.

* 当前结构
- =early-init.el=：启动期设置、窗口默认值与 LF 默认值。
- =init.el=：日常功能入口，保留现有八个分类。
- =lisp/init-func.el=：公共辅助函数、Meow、Eglot、字体。
- =lisp/init-editing.el=：行高亮、尾随空白、Scala 语法回退、大文件保护。
- =lisp/init-diagnostics.el=：Flymake 内置行尾显示、边栏图标与 diff-hl 外观。
- =lisp/init-navigation.el=：Dirvish 侧边树、原生文件 tab、Tabspaces 工作区与搜索范围。
- =lisp/init-tex.el=：首次使用 AUCTeX LaTeX 模式时加载的格式化、折叠、预览。
- =lisp/init-startup.el=、=lisp/init-theme.el=：启动页与主题。
- =archive/legacy/=：已退出启动流程的旧配置，保留供查阅。

* 文件与项目导航
使用 =C-x p p= 选择项目或普通目录，每个项目对应一个工作区。
再次选择同一项目会回到之前的窗口布局。顶部只保留一行：
左侧显示最近编辑窗口的文件，最右侧显示当前工作区名称，点击名称展开全部工作区。
左侧沿用 Dirvish，不需要 Treemacs 或 lsp-mode。导航复用原生 =tab-bar= 的
格式接口、右对齐和弹出菜单，文件顺序与键盘切换继续使用 =tab-line=。
工作区和文件标签采用无立体边框的留白样式，当前编辑窗口的文件标签使用主题强调色，
工作区采用较安静的正文色；切换深浅主题时同步更新。导航使用固定的等宽字体和字号，
不跟随 Org 正文的混合字体或缩放。标签高度由字体自然决定，只保留水平方向的空白。
侧边栏只保留目录标题和文件树，隐藏底部排序信息栏。
长标签保留名称的开头和末尾；拥挤时优先保留当前文件，其余文件可从 =…= 菜单选择。
分屏时，顶部文件标签跟随当前编辑窗口；侧栏或临时面板获焦时保留最近编辑窗口的标签。
在窄窗口中打开目录树时，会按窗口宽度减少树宽。窗口之间使用细分隔线。

| 快捷键 | 操作 |
|--------+------|
| =F8= | 显示或隐藏当前工作区的目录树 |
| =Ctrl+Tab= / =Ctrl+Shift+Tab= | 按固定顺序切换当前编辑窗口的文件（包括收起的标签） |
| =C-x b= | 搜索当前工作区已打开的文件 |
| =C-x B= | 搜索全部 buffer、最近文件和书签 |
| =C-x p p= | 切换项目工作区 |
| =C-x p f= | 在工作区项目中找文件 |
| =C-x p s= | 在工作区项目中搜索内容 |
| =C-c TAB s= | 选择工作区 |
| =C-c <left>= / =C-c <right>= | 撤销或重做窗口布局变化 |
| =C-c @ TAB= | 折叠或展开代码块（原 Ctrl+Tab） |

目录树单击目录展开，单击文件打开并保留树中的焦点；按 RET 打开后进入编辑区。
打开目标是最近使用的主编辑窗口，跳过侧边树与底部临时面板。
在工作区中主动打开外部参考文件，会把它加入当前工作区，目录树和默认搜索根目录保持不变。
帮助、输出和目录 buffer 不显示在文件标签里。切换文件不会打乱标签顺序；
统一顶部栏暂不支持拖动文件标签排序。修改过的文件标注 =•=。
当前标签上的 =×= 结束该文件 buffer；未保存时遵循 Emacs 的确认流程，
若其他窗口或工作区也使用同一个 buffer，关闭也会影响它们。

工作区隔离目前用于本次 Emacs 会话；跨启动的 buffer 恢复仍由原有 Desktop 配置负责，
没有同时启用 Tabspaces 的会话保存与自动恢复。第三方子模块保持上游源码，
NeoEmacs/Windows 的 Dirvish 临时 buffer 名称兼容修正在 =init-navigation.el= 中。

* 主题切换
使用 =M-x my/apply-theme-preset= 选择主题，先关闭旧主题再应用新主题。
支持 Doric、Modus 等已安装主题，也支持 =gits=、=matrix=、=circadian= 和 =default= 预设。

状态栏保留彩色分段，从主题的 =mode-line-active= 背景及状态颜色生成配色；
非活动窗口继承 =mode-line-inactive=。diff-hl 使用内置空位图，只显示主题的纯色背景条。
GITS、Matrix 的覆盖色随预设一起关闭，避免影响随后选择的主题。
